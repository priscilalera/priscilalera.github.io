Burger Company

Sitio web responsive para una hamburguesería, desarrollado con HTML, CSS, JavaScript y Bootstrap 5. Incluye catálogo de productos, carrito de compras y formulario de contacto. El proyecto comenzó como un trabajo grupal y posteriormente lo reconstruí de manera individual, replanteando su diseño visual y su implementación.

01

Contexto

La consigna. Diseñar, maquetar y desarrollar un sitio web responsive para una hamburguesería utilizando HTML, CSS, JavaScript y Bootstrap 5, aplicando la metodología mobile first. El sitio debía incluir una página de inicio con banner, carrusel, información destacada y galería de productos; páginas internas, catálogo y una sección de contacto con formulario validado e información de las sucursales.

El punto de partida. La identidad y el contenido inicial surgieron de un trabajo grupal. Sin embargo, la versión existente presentaba problemas de adaptación a distintos tamaños de pantalla, y corregirla resultaba más complejo que empezar de nuevo. Decidí reconstruir el sitio individualmente, conservando su estructura general, redefiniendo la paleta cromática y desarrollando una nueva implementación responsive. También incorporé Bootstrap 5 y resolví las funcionalidades del proyecto con JavaScript y jQuery.

02

El sitio

Seis páginas: inicio, nosotros, productos, sucursales, preguntas frecuentes y contacto. La paleta combina amarillo, rojo y negro, con la tipografía Montserrat.

03

Funcionalidades

El sitio combina componentes de Bootstrap con plugins de jQuery.

Catálogo y carrito de compras

Los productos se cargan con JavaScript desde un archivo de datos y se agregan a un carrito, armado con el plugin Smart Cart, que calcula el subtotal.

Inicio

Contacto

El formulario se valida con JavaScript antes de enviarse, y un botón flotante de WhatsApp acompaña todas las páginas.

04

Responsive

El sitio se maquetó mobile first, con la grilla de Bootstrap, y se adapta a celular, tablet y escritorio.

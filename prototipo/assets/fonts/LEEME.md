# Tipografías de prueba (solo evaluación local)

Ogg (Sharp Type) y Canela (Commercial Type) son fuentes comerciales.
Sus versiones de prueba permiten **solo evaluación privada**: no se pueden publicar en la web.
Para el sitio publicado hace falta comprar la licencia **web** de la familia elegida.

Para verlas en el prototipo, elegí una opción:

1. Instalá las fuentes de prueba en tu computadora (doble clic → Instalar). El prototipo las detecta solo.
2. O copiá los archivos acá, con estos nombres (pueden ser .woff2 u .otf):

```
ogg/Ogg-Regular.otf          ogg/Ogg-Italic.otf
canela/Canela-Regular.otf    canela/Canela-RegularItalic.otf
```

Estas carpetas no deben subirse al repositorio con fuentes de prueba adentro.
